# Selenium Automated Testing Experiment

## Aim
To install and explore Selenium WebDriver for automated browser testing using Java.

## Tools Required
- Java JDK 21
- Apache Maven
- Selenium WebDriver
- Google Chrome
- Visual Studio Code

## Procedure
1. Installed Java JDK and Apache Maven.
2. Added Selenium Java dependency using Maven.
3. Created a Java program to launch Google Chrome.
4. Opened Google and retrieved its page title.
5. Closed the browser using driver.quit().

## Expected Output
Page title: Google

## Result
Explored Selenium WebDriver for basic browser automation using Java.
